# WeeklyDataProject

A Java project for handling weekly data.

## Getting Started

### Prerequisites
- Java 11 or higher
- javac (Java Compiler)

### Running the Project
1. Compile the source code:
   ```
   javac -d bin src/*.java
   ```
2. Run the application:
   ```
   java -cp bin App
   ```

## Project Structure
- `src/`: Source code directory
- `bin/`: Compiled class files
- `README.md`: Project documentation
